# 日常工作流程及注意事项
## 工作流程
### Win

1. 开工前，先执行`git pull`，拉取最新代码。确保Win本地仓库是最新的。

**注意**：结果文件或参数配置检查后再pull，防止覆盖本地修改。

2. 进行代码开发。add、commit、push。

### Ubuntu
1. 开工前，先执行`git pull`，拉取最新代码。确保Ubuntu本地仓库是最新的。
2. 进行代码开发。add、commit、push。
