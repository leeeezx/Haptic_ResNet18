**按顺序（从左到右）书写以下变量**：
1. 地形
2. 轨迹
3. 速度
4. 数据模态
5. 重复实验次数

# 变量解释

- **地形**：数字，从01开始，
01-40D海绵，02-60D海绵，03-80D海绵，04-三层叠EVA泡棉，05-黄豆，06-稻谷，07-木屑（干燥），08-细沙，09-中沙（原先就有的那种），10-水晶沙粗粒（2-4mm），11-粗河沙（5-8mm），12-人造草地，13-地毯，14-混凝土块，15-泥土，16-金属板，17-碎石（待考虑）

- **轨迹**：数字，从1开始
1-垂直下压，力阈值回退，2-阻抗控制水平移动

- **速度**：数字，从1开始，单位为cm/s，采用真实速度数值。
例如，1cm/s写为1，10cm/s写为10

- **数据模态**：数字，从1开始。外置力传感器为s（sensor），内置位移为d（displacement），内置力/力矩为t（tau）
如有特殊单独维度的力或位移，在数字后用该维度的字母标注。例如，外置力传感器只有z力-1sz。
1-外置力传感器（xyz），内置位移，内置力/力矩，
- **重复实验次数**：数字，从01开始，采用重复实验次数数值。

# Dataset
该文件夹位于D盘

## 前缀
t：单独测的测试数据

## 后缀
- f：表示该文件/文件夹已经经过线性插值填充，其内数据频率一致
- p：表示该文件/文件夹已经峰值切割
- p2：表示该文件/文件夹已经经过峰值对齐+前后填充，数据点完全一致。（不可用，前后填充的数据过多）
- f2：删除空行
- ds：降采样
